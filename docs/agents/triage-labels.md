# Triage labels

| Role | Beads label | Meaning |
| --- | --- | --- |
| Needs triage | `needs-triage` | Maintainer evaluation required |
| Needs information | `needs-info` | Waiting for reporter information |
| Ready for agent | `ready-for-agent` | Approved, self-contained implementation work |
| Ready for human | `ready-for-human` | Requires human implementation |
| Will not fix | `wontfix` | Work will not be undertaken |

Use these labels for incoming and implementation work. Wayfinder maps and decision tickets use only their `wayfinder:*` labels.
